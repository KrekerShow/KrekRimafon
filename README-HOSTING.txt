РИМАФОН — СЕЗОН 2
Пакет для размещения на хостинге

ЧТО ЭТО
Статический одностраничный сайт. Сборка, Node.js, база данных и установка
зависимостей не требуются.

КАК РАЗМЕСТИТЬ
1. Загрузить всё содержимое этой папки в корневую папку сайта.
2. Файл index.html должен лежать именно в корне.
3. Не переименовывать Letter.txt, banner.png и rimafon-season2-hero.png:
   страница обращается к ним по этим именам.
4. После публикации проверить главную страницу с компьютера и телефона.

СОСТАВ
- index.html — вся страница, стили и логика.
- content-loader.js — загружает редактируемые данные на публичную страницу.
- site-content.json — правила, настройки сезона, идеи и их изображения.
- admin.html — автономная панель редактирования.
- rimafon-season2-hero.png — основная иллюстрация.
- banner.png — резервная иллюстрация на случай ошибки загрузки основной.
- Letter.txt — список идей для рулетки в формате JSON; новый сезон начинается
  с пустого массива []. Оставлен для совместимости со старой версией.
- .nojekyll — позволяет без лишней обработки размещать сайт на GitHub Pages.

ВАЖНО
- Все пути к локальным файлам относительные, поэтому сайт можно разместить
  как на отдельном домене, так и в подпапке.
- Шрифт Rubik загружается через Google Fonts. Если сервис недоступен,
  автоматически используется системный шрифт.
- DonationAlerts, Twitch, YouTube, Telegram, Discord, Steam и Boosty являются
  обычными внешними ссылками.
- Letter.txt должен оставаться корректным JSON-массивом. Сейчас его содержимое: []

КАК ПОЛЬЗОВАТЬСЯ АДМИН-ПАНЕЛЬЮ
1. После размещения открыть адрес сайта с /admin.html в конце.
2. Загрузить архив PointAuc либо добавить идеи вручную.
3. При необходимости изменить правила и параметры сезона.
4. Прикрепить картинки к нужным идеям. Панель автоматически уменьшает их и
   сохраняет внутри файла данных.
5. Нажать «Сохранить черновик» для продолжения работы в этом же браузере.
6. Нажать «Предпросмотр», чтобы увидеть черновик на публичной странице.
7. Нажать «Скачать данные сайта». Панель создаст файл site-content.json.
8. Заменить этим файлом site-content.json в корне хостинга.

Админ-панель намеренно не изменяет хостинг напрямую. Благодаря этому она
работает на любом статическом хостинге и не требует пароля или серверной базы.
Доступ к загрузке файлов на хостинг должен оставаться только у владельца сайта.

ПОДХОДЯЩИЙ ХОСТИНГ
GitHub Pages, Netlify, Vercel в режиме Static, Cloudflare Pages либо обычный
веб-сервер nginx/Apache.
